## 新增的 make 目标

### `release` — 生产发布

```bash
make release ENV=prod
```

- 调用 `dotnet publish -c Release --runtime win-x64 --self-contained`
- 产物输出到项目根目录下的 `publish\` 文件夹
- 包含运行时（self-contained），**目标机器无需安装 .NET**
- 因为 `.csproj` 里已有 `WindowsAppSDKSelfContained=true`，Windows App SDK 依赖也会一并打包

可以自定义输出目录：

```bash
make release RELEASE_DIR=out ENV=prod
```

---

### `install` — 发布并安装到指定目录

```bash
make install INSTALL_DIR="C:\Apps\FluentGallery"
```

- 先自动执行 `release`，再用 `robocopy` 将 `publish\` 同步到目标路径
- 目标目录不存在会自动创建

---

## 安装到本机的推荐步骤

1. 选一个你想放程序的目录，比如 `C:\Apps\FluentGallery` 或 `D:\Programs\FluentGallery`

2. 运行：
   ```bash
   make install INSTALL_DIR="C:\Apps\FluentGallery"
   ```

3. 在安装目录里找到 `FluentGallery.exe`，右键 → **发送到桌面快捷方式**，即可从桌面启动

> 注意：因为是 unpackaged 应用（`WindowsPackageType=None`），不会注册到开始菜单，也不支持 Windows 卸载程序，管理完全靠这个目录本身。若要卸载，直接删除整个目录即可。

**根本原因总结：**

| 方式 | 问题 |
|------|------|
| `dotnet publish --self-contained` | Windows App SDK bootstrapper (MddBootstrapInitialize2) 在自包含模式下崩溃，exit 0xC000027B |

| **`dotnet build -c Release --no-self-contained`** ✅ | 与 Debug 构建完全一致，Windows App SDK DLL 全部到位 |
